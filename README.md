# Student Performance Analysis and Prediction Using R

## Project Overview

This project focuses on analyzing student academic performance using R programming. It uses student information and academic grades to understand patterns in performance and predict final grades using a linear regression model.

## Objectives

- Analyze student academic data.
- Perform data cleaning and preprocessing.
- Calculate descriptive statistics and correlations.
- Visualize student grades and selected factors.
- Build a linear regression model to predict final grades.
- Evaluate the model using suitable regression metrics.

## Dataset

The project uses the Student Performance dataset, preferably the Mathematics dataset from the UCI Machine Learning Repository.

Dataset source: https://archive.ics.uci.edu/dataset/320/student+performance

The dataset includes student-related information and academic grades. The final grade variable, `G3`, is used as the prediction target when available.

## Tools and Technologies

- R Programming
- RStudio
- CSV dataset
- Data visualization
- Linear regression

## Project Workflow

1. Load the dataset into R.
2. Check the dataset structure and summary.
3. Check missing values and duplicate records.
4. Perform data analysis and visualization.
5. Examine relationships between selected variables.
6. Split the data into training and testing sets.
7. Train a linear regression model.
8. Predict final grades and evaluate model performance.

## Results

The final results, including regression coefficients, predictions, R-squared, RMSE, and MAE, are reported in the project output files after analysis.

## Conclusion

This project demonstrates how R programming can be used to analyze student performance and build a model for predicting final grades. The predictions depend on the available data and selected variables, so they should be interpreted carefully.
